# 项目自定容差 V1

依据用户2026-11-03授权，固定本项目内部仿真代理与决策开发的数值要求。参考GB/T 19804和ISO 13920对几何公差分类管理的思路；下述数值由项目自行选定，不是标准表格值，不代表符合这些标准。

## 工艺输出限值

| 指标 | 固定上限 | 设定用途 |
|---|---:|---|
| 最终最大总位移幅值 | 0.10 mm | 项目残余变形控制目标 |
| 最终最大等效总应变 | 0.030，即3% | 项目应变筛选目标 |
| 最终最大等效塑性应变 | 0.030，即3% | 项目塑性应变筛选目标 |

选择0.10 mm作为内部变形控制尺度；分配其10%即0.01 mm给代理误差。两项应变目标统一设为0.03，代理误差分配0.005。该分配是明确、可复现的开发设计假设，不是从材料强度或焊缝缺欠等级推导的安全限值。应变3%不能据此解释为材料安全。

## 前向代理误差验收

分别对两种顺序评价冻结测试集绝对误差95分位数：

- 最大总位移：P95 ≤ 0.010 mm。
- 最大等效总应变：P95 ≤ 0.005。
- 最大等效塑性应变：P95 ≤ 0.005。

弹性应变与方向位移暂为辅助指标，继续报告误差，不宣称已设置独立验收容差。全局P95达标不意味着每个区域达标，区域误差仍须单独查看。此规则是在查看首版结果后制定，属于开发基准，最终发布还需新仿真点验证。

## 决策门槛

代理点预测采用固定误差余量：位移预测≤0.09 mm，总应变及塑性应变预测≤0.025；同时检查校准上界不超过对应输出限值。该门槛仅包含代理误差，尚未覆盖网格离散、模型形式和实际制造误差。

已有ANSYS工况筛选使用仿真输出与工艺限值比较。代理模型通过上述误差验收，并不等于ANSYS已得到实验验证，也不等于产品验收合格。

## 配置与版本

机器可读配置：configs/engineering_tolerances.json。此次固定为V1，后续变更须保留依据和版本，不能为了让模型达标而静默放宽。
