# 数据与物理口径

输入：电流A、电压V、ambient_C温度℃、速度m/s、process_order类别1/2。

顺序1先volume 9后volume 7；顺序2相反。均完成两条焊缝。

ambient_C同时用于TUNIF、TREF、对流环境温度和材料参考温度。模型只适用于这种联动设置。

输出均在SET,LAST提取：冷却约90分钟后的最大等效弹性/总/塑性应变，以及总位移和各方向位移幅值。应变无量纲，位移m；方向符号已丢失。各指标最大值可能不在同一节点，不能简单相加重构。

固定三点支撑、几何、材料、网格、热源和冷却口径。新增批次在导入前必须核对这些设置；不同设置不要直接混入同一模型。目前批次文件仅登记来源，尚不自动验证ANSYS设置。

失败记录不作为零输出，也不直接作为物理不可行标签。应另行调查失败原因。

当前模型不提供变形方向、完整云图、焊接质量或不同结构下的预测保证。工程误差阈值尚未确定，所有模型为候选版本。
